PERFEKT-BASIS FINAL – SUBTITLE TIMING FIX

Starting point:
- SchlauWutzie_Perfekt.zip (known-good user supplied basis)

Changed only the subtitle timing conversion:
- DTW `t_dtw` is a TOKEN START timestamp, not an end timestamp.
- The old parser used `end = start` for DTW tokens.
- The new parser closes each word at the next word's DTW start when available,
  otherwise it uses normal token/segment timestamps.
- Timing is forced monotonically forward across the COMPLETE audio timeline.
- Missing/non-monotonic DTW values fall back to normal token timestamps.
